# r34-sh
### r34 browser running on the kitty graphics protocol

<img width="800" height="600" alt="1000010513" src="https://github.com/user-attachments/assets/c395635d-90bf-425d-a23b-5914c61f2372" />


## FEATURES
- search for stuff
- jump between images / pages using 'wasd'
- display full-size images using 'f'
- download images using 'c'

## DEPENDENCIES
- a Terminal Emulator compatible with the kitty graphics protocol
- bash, tput, kitten, curl, grep, sed
